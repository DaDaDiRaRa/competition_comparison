# 설계공모 경쟁분석 시스템

## 1. 설치 및 실행

### 필요 환경

- Python 3.10 이상
- Node.js 18 이상
- Anthropic API 키 ([console.anthropic.com](https://console.anthropic.com)에서 발급)

### 설치

```powershell
# 저장소 클론
git clone <저장소 주소>
cd competition_comparison

# 백엔드 패키지 설치
cd competition-analyzer/backend
pip install -r requirements.txt

# 프론트엔드 패키지 설치
cd ../frontend
npm install
```

### 실행 (매번)

터미널 2개를 열어 각각 실행합니다.

**터미널 1 — 백엔드:**
```powershell
cd competition-analyzer/backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**터미널 2 — 프론트엔드:**
```powershell
cd competition-analyzer/frontend
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

## 2. 첫 실행 설정

앱을 처음 실행하면 API 키 입력 화면이 나타납니다.

### API 키 입력

1. [console.anthropic.com](https://console.anthropic.com) → API Keys → 새 키 생성
2. 앱 화면에 `sk-ant-...` 형태의 키 붙여넣기 → **적용**

> **주의:** API 키는 서버 메모리에만 저장됩니다. 앱(백엔드)을 재시작하면 다시 입력해야 합니다.

### DB 경로 확인

**설정 탭**을 열어 `DB 경로`를 확인하세요. 이 경로에 모든 분석 데이터가 저장됩니다.  
기본값이 다른 컴퓨터의 경로로 되어 있다면, `backend/app_settings.json`을 직접 열어 `db_path`를 수정하세요.

## 3. 전체 사용 흐름

```
[데이터 축적]                    [진단]
경쟁 공모 등록 ──▶ 비교분석 실행 ──▶ 패턴 학습 ──▶ 새 제안서 진단
내 프로젝트 등록 ─╯
```

### 권장 순서

1. **경쟁 공모 등록** — 과거 공모의 지침서 + 여러 회사 제안서를 업로드해 데이터 축적
2. **비교분석 실행** — 저장된 공모 카드에서 버튼 클릭 → AI가 제안서 간 비교 분석
3. (반복) 여러 공모를 등록할수록 진단 정확도가 올라갑니다
4. **제안서 진단** — 새로 작성 중인 제안서 PDF를 업로드해 당선 패턴과 비교

## 4. 탭별 기능 안내

### 경쟁 공모 등록 탭

과거 또는 진행 중인 공모의 **여러 회사 제안서**를 한 번에 등록합니다.

#### 입력 항목

| 항목 | 설명 | 필수 |
|---|---|---|
| 시설유형 | 공공시설 / 재건축 / 주거 / 업무 등 | ✅ |
| 프로젝트번호 | 사내 관리번호 (예: 26-014) | ✅ |
| 프로젝트명 | 공모 이름 (예: 영등포구 신청사) | ✅ |
| 발주처 | 발주 기관명 | 선택 |
| 위치 | 대지 위치 | 선택 |
| 지침서 PDF | 공모 지침서 파일 | 선택 |
| 제안서 목록 (JSON) | 각 회사 정보 입력 (아래 참고) | ✅ |
| 제안서 PDF | 각 회사의 제안서 PDF 파일들 | ✅ |

#### 제안서 목록 JSON 작성법

```json
[
  { "company": "건축사사무소A", "result": "win" },
  { "company": "건축사사무소B", "result": "lose" },
  { "company": "건축사사무소C", "result": "lose" }
]
```

- `result` 값: `win`(당선) / `lose`(낙선) / `contracted`(수의계약)
- PDF 파일 업로드 순서와 JSON 순서가 **정확히 일치**해야 합니다

#### 처리 순서

1. **데이터 추출 시작** 클릭 → AI가 각 PDF를 페이지별로 분류·분석
2. 완료 후 상단 **저장된 공모 목록**에 카드가 생성됨
3. 카드의 **비교분석 실행** 버튼 클릭 → 제안서 간 AI 비교 분석 실행
4. 분석 완료 후 **비교 리포트 열기** 링크로 HTML 리포트 확인

> **팁:** 데이터 추출과 비교분석은 분리되어 있습니다. 추출 후 바로 비교분석이 자동으로 시작되지 않습니다.

---

### 내 프로젝트 등록 탭

자사가 참여한 공모 제안서를 **1개씩** 등록합니다. 당선/낙선 결과를 함께 기록해 DB에 쌓으면 진단 정확도가 높아집니다.

#### 입력 항목

경쟁 공모 등록과 동일하되, 회사 이름과 결과를 직접 입력합니다.

- **회사명:** 자사 이름 (일관되게 사용)
- **결과:** 당선 / 낙선 / 수의계약

---

### 제안서 진단 탭

현재 작업 중인 제안서를 업로드하면 **과거 당선작 패턴과 비교**해 강점·약점·보강 포인트를 분석합니다.

#### 진단 기준 선택

| 모드 | 설명 |
|---|---|
| **전체 당선 패턴 (자동)** | DB에 쌓인 해당 시설유형의 모든 당선작 통계 기반 |
| **특정 공모 선택** | 비교하고 싶은 공모를 직접 골라 기준 설정 |

#### 진단 결과 화면

- **종합점수** (0~10): 당선 패턴 대비 전체 점수
- **정량 지표 비교 바**: 연면적·용적률 등 수치를 당선 평균 / 낙선 평균 / 내 제출물로 나란히 비교
- **페이지 구성**: 실제 페이지 분포
- **지침서 충족도**: 지침서 제출 시 요구사항별 충족 여부
- **패턴 편차 경고**: 당선작 대비 누락된 페이지 유형, 정량 지표 이상 감지
- **축별 점수**: 각 평가 항목 상세 (강점·약점·근거)
- **보강 포인트**: 우선순위 개선 사항

분석 완료 후 **진단 리포트 열기** 버튼으로 독립적인 HTML 파일로 저장된 리포트를 열 수 있습니다.

---

### 교차 비교 탭

**서로 다른 공모**에서 특정 제출물을 골라 직접 비교합니다.

- 여러 공모의 제출물을 자유롭게 선택 (체크박스)
- **교차 비교 실행** 클릭 → AI가 선택된 제출물들을 일대일 비교
- 과거 생성된 교차 비교 리포트는 하단 **이전 리포트** 목록에서 재열람 가능

---

### 설정 탭

#### API 키 관리

- 현재 설정된 키 상태 표시 (설정됨 / 미설정)
- 키 입력 후 **키 적용** → 앱 재시작 전까지 유효

#### 모델 설정

- 기본값: `claude-sonnet-4-6`
- 변경 후 **모델 설정 저장** 클릭

#### 패턴 뷰어

설정 탭 하단에서 시설유형별로 축적된 당선·낙선 패턴 통계를 확인할 수 있습니다.

| 섹션 | 내용 |
|---|---|
| 페이지 구성 통계 | 당선 vs 낙선 평균 페이지 수 (파란 막대 vs 주황 막대) |
| 정량 지표 평균 | 연면적·용적률 등 당선 vs 낙선 수치 비교 |
| 컨셉 키워드 | 당선작에 자주 등장한 키워드 (녹색), 낙선 우세 키워드 (적색) |
| 질적 인사이트 | 과거 공모 분석에서 추출한 당선 패턴·낙선 패턴·차별화 요소 |

**패턴 재구축** 버튼: 새 공모를 등록한 후 클릭하면 최신 데이터로 패턴 통계가 갱신됩니다.

## 5. 용어 설명

| 용어 | 설명 |
|---|---|
| **시설유형** | 공모의 건물 종류 (공공시설, 재건축, 주거, 업무 등). 같은 유형끼리 패턴 비교 |
| **공모 (프로젝트)** | 하나의 설계공모 단위. 지침서 + 여러 제출물로 구성 |
| **제출물 (submission)** | 한 회사의 제안서 PDF 1개 |
| **당선작 패턴** | DB에 쌓인 같은 시설유형 당선작들의 통계적 특성 |
| **낙선 패턴** | 낙선작들의 통계 (당선 패턴과 비교해 경고 기준으로 사용) |
| **비교분석** | 동일 공모 내 제출물들을 AI가 8개 평가축으로 채점·비교 |
| **진단** | 단일 제출물을 과거 당선 패턴과 비교해 강약점 분석 |
| **리포트** | AI 분석 결과를 담은 HTML 파일 (브라우저에서 열림, Ctrl+P로 PDF 저장 가능) |

## 6. 자주 묻는 질문

**Q. 데이터 추출을 완료했는데 비교 리포트 링크가 없어요.**  
A. 데이터 추출과 비교분석은 분리되어 있습니다. 저장된 공모 카드에서 **비교분석 실행** 버튼을 클릭해야 리포트가 생성됩니다.

**Q. 비교분석 실행 버튼이 없고 "리포트만 재생성" 버튼만 있어요.**  
A. 이미 비교분석이 완료된 공모입니다. "리포트만 재생성"은 LLM을 다시 호출하지 않고 기존 분석 결과로 HTML만 다시 만듭니다. 비교분석 자체를 다시 하려면 카드 메뉴에서 "비교분석 실행"을 찾으세요.

**Q. 진단에서 "해당 유형 당선 데이터 없음"이 뜨는데요.**  
A. 해당 시설유형의 당선작이 DB에 없습니다. 경쟁 공모 등록 또는 내 프로젝트 등록으로 `result: "win"` 제출물을 먼저 등록하고, **설정 탭 → 패턴 재구축**을 클릭하세요.

**Q. 앱을 재시작했더니 API 키가 사라졌어요.**  
A. 보안을 위해 API 키는 디스크에 저장하지 않습니다. 백엔드를 재시작할 때마다 설정 탭에서 다시 입력해야 합니다.

**Q. PDF 파일 순서와 JSON 순서를 맞추는 게 어렵습니다.**  
A. 파일명을 회사명으로 지정해두면 실수를 줄일 수 있습니다. 예: `건축사무소A.pdf`, `건축사무소B.pdf`. JSON도 같은 순서로 작성.

**Q. 리포트를 PPT처럼 출력하고 싶어요.**  
A. 리포트를 브라우저에서 열고 **Ctrl+P** → "PDF로 저장" 선택. A4 가로 형식으로 최적화되어 있습니다.

**Q. API 비용은 얼마나 드나요?**  
A. 제출물 1개 기준 추출에 약 $0.10~0.30, 비교분석에 약 $0.20~0.50 정도 소요됩니다 (페이지 수·DPI에 따라 다름). 진단은 약 $0.10~0.20. 정확한 비용은 Anthropic 콘솔에서 확인하세요.
